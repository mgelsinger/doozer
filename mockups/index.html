Doozer

Five ways to keep a small creature on your desktop. Every version runs the same pet — same needs, same moods, one shared save — so what you are choosing between is how Doozer looks, where it lives, and how you touch it.

  1. Play with each one. Open a card below. The Review tools panel speeds up time and makes Doozer needy on demand.
  2. Try it on your real desktop. Run npm run pet, then right-click Doozer to switch version.
  3. Tick what you like in the checklist at the bottom and hit Copy my picks. Paste that back to Claude.
